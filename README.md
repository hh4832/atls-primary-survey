# 急診外傷病人的評估處置原則

ATLS 11th Chapter 1 教學用網頁簡報，繁體中文、15 張投影片，含手機閱讀模式。

## 使用

開啟 `index.html`。手機可使用連續閱讀模式，桌面可使用逐頁播放。

## GitHub Pages

1. 建立 `atls-primary-survey` repository。
2. 將這份資料夾的檔案上傳至 `main` 分支根目錄（包含 `.github/workflows/deploy.yml`）。
3. 於 **Settings → Pages → Build and deployment → Source** 選擇 **GitHub Actions**。
4. 於 Actions 確認 `Deploy static teaching deck to GitHub Pages` 執行成功。

## 來源與聲明

參考 ACS ATLS 11th edition Chapter 1，自行整理的教學資料。圖片僅供教育用途。臨床請依院內標準流程及最新指引執行。
